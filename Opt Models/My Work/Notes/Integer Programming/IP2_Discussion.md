# 整数规划 (Integer Programming) 示例问题讨论

本笔记总结了关于 `Opt Models/Lecture/IP2.pdf` 中 `Integer Programming Examples` 部分的四个问题的讨论，重点解释了 `U` 和 `L` 的含义和应用。

## 概念解析：未使用的预算计入总净现值 (NPV)

在资本预算问题中，"all unused portions of budget count toward total NPV" 的意思是：**没花出去的预算也算进你要最大化的“总价值”里**。

也就是说，目标不是只最大化“项目 NPV 之和”，而是：

> **总价值 = 所选项目的 NPV 之和 + 未使用的预算**

**例如：**
- 选项目 1、2、5
- 投入：5.5 + 6.5 + 10.5 = 22.5K
- 项目 NPV：15 + 19 + 29 = 63K
- 未用预算（总预算 $23K）：23 − 22.5 = 0.5K
- **总价值 = 63 + 0.5 = 63.5K**

这里没有把 NPV 和投资成本相加。实际在加的是两类东西：
1.  **项目产生的 NPV**：你选中的项目在未来带来的净现值。
2.  **未用预算**：剩在手里的现金。

从“总财富”角度：总财富 = 投资的未来价值（NPV 之和）+ 手头的现金（未用预算）。
所以这里的 “total NPV” 是“总价值”的广义说法，包含了项目价值和现金两部分。

**数学上的等价建模：**
最大化：
$$\text{Total Value} = \sum_i \text{NPV}_i \cdot x_i + (B - \sum_i \text{Cost}_i \cdot x_i)$$
其中 \\(B=23\\) 是总预算，\\(x_i \\in \\{0,1\\}\\) 表示是否选项目 \\(i\\)。
整理后：
$$\text{Total Value} = B + \sum_i (\\text{NPV}_i - \\text{Cost}_i) \\cdot x_i$$
由于 \\(B\\) 是常数，所以等价于最大化 \\(\\sum_i (\\text{NPV}_i - \\text{Cost}_i) \\cdot x_i\\)。

## 背包问题 (Knapsack Problem)

Knapsack (背包问题) 是一个经典的组合优化问题。
-   **背包容量**：公司的总预算。
-   **物品**：每个投资机会。
-   **物品重量/成本**：每个投资项目的成本。
-   **物品价值**：每个投资项目的净现值 (NPV)。
目标是在不超过总预算的前提下，使总价值最大化。

## Event 1 的真值表与约束

Event 1 是“要么投资 2，要么投资 3，但不能同时投资”。

| Investment 2 (x2) | Investment 3 (x3) | 有效？ |
|-------------------|-------------------|--------|
| 0                 | 0                 | 是     |
| 0                 | 1                 | 是     |
| 1                 | 0                 | 是     |
| 1                 | 1                 | 否     |

在整数规划中，我们通常避免使用乘法来构建线性约束（如 \\(x_2 \\cdot x_3 < 1\\)），因为它会引入非线性。最常见的线性表示是：
$$x_2 + x_3 \\le 1$$

## Event 5 的单一约束推导

Event 5 的逻辑条件是：“**如果投资 2 被选中 (x2=1)，那么投资 4 (x4=1) 和投资 6 (x6=1) 也必须被选中。**”

**单一约束：**
$$x_2 \\le \\frac{x_4 + x_6}{2}$$

**验证：**
1.  **如果 \\(x_2 = 0\\)**：\\(0 \\le \\frac{x_4 + x_6}{2}\\)，恒成立。\\(x_4, x_6\\) 可以是任意值（0 或 1），符合逻辑。
2.  **如果 \\(x_2 = 1\\)**：\\(1 \\le \\frac{x_4 + x_6}{2} \\implies x_4 + x_6 \\ge 2\\)。由于 \\(x_4, x_6\\) 都是二元变量，唯一满足此条件的是 \\(x_4 = 1\\) 且 \\(x_6 = 1\\)。符合逻辑。

## 整数规划示例问题

### 问题 1: 如何限制变量 x 只能取集合 {2, 7, 12} 中的一个值？

**建模方法：**
设 \\(x\\) 是一个整数变量。\n引入三个二元辅助变量 \\(y_1, y_2, y_3 \\in \\{0, 1\\}\\)：
**约束：**
1.  **\\(x\\) 的值必须是其中之一：**
    $$x = 2y_1 + 7y_2 + 12y_3$$
2.  **只能选择一个值：**
    $$y_1 + y_2 + y_3 = 1$$

### 问题 2: 如何限制变量 x 只能取集合 {0, 2, 7, 12} 中的一个值？

**建模方法：**
设 \\(x\\) 是一个整数变量。\n引入四个二元辅助变量 \\(y_0, y_1, y_2, y_3 \\in \\{0, 1\\}\\)：
**约束：**
1.  **\\(x\\) 的值必须是其中之一：**
    $$x = 0y_0 + 2y_1 + 7y_2 + 12y_3 \\implies x = 2y_1 + 7y_2 + 12y_3$$
2.  **只能选择一个值：**
    $$y_0 + y_1 + y_2 + y_3 = 1$$

### 问题 3: 如何限制变量 x 要么为 0，要么在特定的正数区间内？

这个问题是说 \\(x\\) 可以等于 0，或者 \\(x\\) 必须在一个正数区间 \\([L, U]\\) 内（例如，\\(L > 0\\)）。

**U 和 L 的含义：**
这里的 `U` (Upper bound) 和 `L` (Lower bound) 是指问题中给定的“**特定的正数区间**”的**上限**和**下限**。它们是**已知参数**，而不是需要求解的变量。

**举例说明：**
如果要求 \\(x\\) 要么等于 0，要么 \\(x\\) 必须在 **5 到 10 之间**（包括 5 和 10），那么：
-   **L = 5**
-   **U = 10**

**建模方法：**
设 \\(x\\) 是一个连续变量（或整数变量，取决于具体问题）。\n引入一个二元辅助变量 \\(y \\in \\{0, 1\\}\\)：
**约束：**
1.  **连接 \\(x\\) 和 \\(y\\)，并设置上限：**
    $$x \\le U \\cdot y$$
2.  **连接 \\(x\\) 和 \\(y\\)，并设置下限：**
    $$x \\ge L \\cdot y$$

### 问题 4: 如何实现“约束 A 或 约束 B 必须成立”的逻辑？

假设我们要实现以下逻辑：`约束 A` 必须成立 **或者** `约束 B` 必须成立。

**具体例子：**
我们想限制一个变量 `x`：
-   要么 `x <= 5` (约束 A)
-   要么 `x >= 10` (约束 B)
即：`x <= 5` **或者** `x >= 10`。

**建模方法 (使用 Big M 方法)：**
引入一个二元辅助变量 \\(y \\in \\{0, 1\\}\\)：
-   如果 \\(y=0\\)，则约束 A (`x <= 5`) 成立。
-   如果 \\(y=1\\)，则约束 B (`x >= 10`) 成立。

**约束：**
1.  **约束 A 及其松弛形式：**
    $$x \\le 5 + M \\cdot y$$
2.  **约束 B 及其松弛形式：**
    $$x \\ge 10 - M \\cdot (1 - y)$$
3.  **二元变量声明：**
    $$y \\in \\{0, 1\\}$$

### 大于/小于符号对 M 的影响

`M` 的作用是让一个约束在特定条件下失效。它的具体值和正负号取决于原始约束的不等号方向。

**核心思想：**
-   对于 `A <= B` 形式的约束，要使其失效，需要将 `B` 增加一个足够大的正数 `M`。
-   对于 `A >= B` 形式的约束，要使其失效，需要将 `B` 减少一个足够大的正数 `M`。

**`M` 的具体数值：**
`M` 必须是一个足够大的正数，以保证当约束被松弛时，它不会错误地限制可行域。通常，`M` 可以估计为变量可能取值的最大范围，或者问题中系数可能达到的最大差值。

### `x` 的正负性对 M 的影响

`x` 的正负性本身并不会直接改变 `M` 的代数符号（`M` 始终是一个正数）。但是，它会影响 `M` **需要取多大的值**，以确保松弛的约束确实是无效的。
本质上，`x` 的定义域（是正数、负数、还是任意实数）决定了我们计算 `M` 时需要考虑的边界范围。

## 分段线性函数 (Piecewise Linear Functions)

分段线性函数用于处理目标函数或约束中出现的**非线性但可以分段表示为线性的关系**。在优化问题中，很多实际情况下的成本、收益或关系不是简单的一条直线，而是在不同区间内有不同的斜率或常数项。

### 与固定成本 (Fixed Costs) 的关系

`Modeling Fixed Costs` 是分段线性函数的一个典型应用。固定成本的特点是：
-   当产量为 0 时，成本为 0。
-   当产量大于 0 时，无论产量多少，都会产生一个固定成本 `d_j`，然后再加上按产量计算的变动成本 `c_j * x_j`。

这种成本函数图像上会有一个“跳跃”，在 `x=0` 处有一个断点。它可以用一个分段函数来表示：
$$
\\text{Cost}(x_j) = 
\\begin{cases} 
0 & \\text{if } x_j = 0 \\\\
d_j + c_j x_j & \\text{if } x_j > 0
\\end{cases}
$$
通过引入二元变量 \\(y_j\\) 和 \\(x_j\\) 之间的线性约束，就可以把这个分段线性的关系“翻译”成整数规划的线性约束。

## 变量读音：\\(\\delta_1, \\delta_2, \\delta_3\\)

图片中出现的变量 \\(\\delta_1, \\delta_2, \\delta_3\\) 中的希腊字母是 **delta** (德尔塔)。
因此，它们的读音分别是：
-   \\(\\delta_1\\) 读作：**delta-one** (德尔塔-一)
-   \\(\\delta_2\\) 读作：**delta-two** (德尔塔-二)
-   \\(\\delta_3\\) 读作：**delta-three** (德尔塔-三)
在数学和科学中，delta 常用作变量或表示变化量。在这里，结合上下文，它们很可能代表了某种分段或增量变量。

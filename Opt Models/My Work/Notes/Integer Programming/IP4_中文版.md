## 求解整数规划简介

### 概述
整数规划(IP)是一类优化问题，其中部分或全部决策变量必须取整数值。本讲座涵盖两种基本的算法方法：
- **分支定界算法 (Branch and Bound)**
- **割平面算法 (Cutting Planes)**

此外，我们还探讨如何使用商业求解器（如Gurobi）实现这些算法。

---

## 分支定界算法

### 概念与动机
分支定界(B&B)算法是一种系统化的整数规划求解方法。基本思想是：
1. 放松整数约束得到线性规划(LP)
2. 递归地划分解空间
3. 使用界来消除不可能包含最优解的分支

### 步骤详解

#### 步骤1：线性松弛
从原始整数规划问题中去除整数约束，得到线性规划松弛。这个LP提供了最大化问题最优整数解的**上界**。

#### 步骤2：检查解的整数性
求解LP松弛：
- 若最优解全部为整数，则找到了IP的最优解
- 若最优解含有分数值，进行步骤3

#### 步骤3：分支
选择一个含分数值的变量，创建两个子问题：
- **子问题1:** 添加约束，该变量向下取整
- **子问题2:** 添加约束，该变量向上取整

这样将解空间划分为更小的区域，分别递归求解。

#### 步骤4：剪枝/删除
满足以下条件之一的节点可被剪枝：
- LP松弛无可行解
- LP松弛的最优值小于当前已知最优整数解
- LP松弛的最优解为整数（找到可行的整数解）

**关键洞察:** 通过维护目前发现的最优整数解，我们可以提前删除许多分支，显著减少计算量。

### 算法性质

**优点：**
- 在实际应用中通常表现良好
- 保证找到最优解（如果问题有界）

**缺点：**
- 没有关于收敛时间的理论保证
- 对于包含大量二进制/整数变量的大规模问题可能很慢

### 混合整数规划(MIP)
对于仅部分变量需要整数性的混合整数规划：
- 只在整数约束变量上分支
- 子问题的LP松弛可能仍包含分数整数变量
- 相同的剪枝策略适用

## 割平面算法

### 动机：超越LP松弛

#### 问题表述的多样性
同一个整数规划可以有多种表述方式：
- 所有表述得到相同的整数解
- 但其对应的LP松弛可能差异很大
- 不同的LP松弛提供不同的界（某些界更紧）

**关键观察:** 更紧的LP松弛界使我们更接近真实整数最优值，需要的分支更少。

### 示例：LP vs IP解

考虑一个简单的IP：
$$\max \, c^T x$$
$$\text{约束条件:} Ax \leq b$$
$$x \text{ 为整数}$$

LP松弛的最优解可能是分数，距任何可行整数解较远。然而，我们可以添加**割平面**（有效不等式）来改进LP，这些割平面：
- 消除分数LP解
- 不消除任何可行整数解

### 寻找有效不等式

#### 一般方法：Chvátal-Gomory (CG)割

**定义:** **有效不等式**是一个线性约束，满足所有可行整数解，但可能被LP松弛解违反。

考虑一个通用的整数规划：
$$\max \, c^T x$$
$$\text{约束条件:} Ax \leq b$$
$$x \geq 0, \text{ } x \text{ 为整数}$$

**CG割的构造:**

1. 选择任意向量 $u$，其中 $u_i \geq 0$
2. 计算: $u^T A x \leq u^T b$
3. 因为 $x$ 是整数，可将系数向下取整: $\lfloor u^T A \rfloor x \leq \lfloor u^T b \rfloor$
4. 这得到一个有效不等式，可能削除分数解

**为什么有效:** 关键在于由于 $x$ 的整数性，可向下取整右侧而不违反任何整数可行解的约束。

#### 示例：Chvátal-Gomory割 - 详细解释

给定系统：
$$\max \, 3x_1 + 2x_2$$
$$\text{约束条件:} 10x_1 + 6x_2 \leq 45$$
$$x_1, x_2 \geq 0, \text{ 整数}$$

**步骤1：求解LP松弛**
- 去除整数约束
- LP最优：$(4.5, 0)$，$Z_{LP} = 13.5$
- **问题**：不是整数！

**步骤2：选择乘数向量并组合约束**

这是关键步骤！选择 $u = 0.5$ 并乘以约束：
$$0.5 \times (10x_1 + 6x_2 \leq 45)$$
$$5x_1 + 3x_2 \leq 22.5$$

**为什么有效：**
- 我们通过缩放创建新的有效不等式
- 因为 $x_1$ 和 $x_2$ 必须是整数，所以 $5x_1 + 3x_2$ 也必然是整数
- 任何 $\leq 22.5$ 的整数也 $\leq \lfloor 22.5 \rfloor = 22$

**步骤3：向下取整（魔法时刻！）**

$$\lfloor 5 \rfloor x_1 + \lfloor 3 \rfloor x_2 \leq \lfloor 22.5 \rfloor$$
$$5x_1 + 3x_2 \leq 22$$

这就是**Chvátal-Gomory（CG）割**！

**步骤4：验证其威力**

- LP最优 $(4.5, 0)$：$5(4.5) + 3(0) = 22.5 \not\leq 22$ ✗ **被削除！**
- 整数解 $(4, 0)$：$5(4) + 3(0) = 20 \leq 22$ ✓ **被保留！**

这演示了CG割的关键特性：
- **消除分数LP解**
- **保留所有整数可行解**

#### CG割为什么有效：数学性质

**关键性质1：为什么可以向下取整？**

如果 $x$ 是整数向量，$\lfloor A \rfloor$ 是向下取整的系数矩阵：
$$\lfloor A \rfloor x = \text{（整数向量）} \times \text{（整数向量）} = \text{（整数）}$$

所以如果整数解满足 $Ax \leq b$，则：
$$\lfloor A \rfloor x \leq \lfloor Ax \rfloor \leq \lfloor b \rfloor$$

**关键性质2：为什么不删除整数解？**

对于满足原始约束的任何整数可行解 $x^*$：
1. 从以下开始：$Ax^* \leq b$
2. 用 $u \geq 0$ 乘以：$u^T Ax^* \leq u^T b$
3. 因为 $x^*$ 是整数：$u^T Ax^*$ 是整数
4. 因此：$\lfloor u^T A \rfloor x^* \leq \lfloor u^T b \rfloor$（CG割被满足！）

**关键性质3：为什么消除分数解？**

LP最优 $(4.5, 0)$ 满足原始约束，但：
- 计算：$5(4.5) + 3(0) = 22.5$
- 但CG割要求：$\leq 22$
- 因为 $22.5 > 22$，LP最优被**削除** ✗

**实际应用：**
- 迭代应用多个CG割来逐步消除分数空间
- 每个割都紧化LP界：原始LP界 $13.5$ → 新LP界 $12$ → 等等
- 最终LP最优变得（近似）整数
- $u$ 的选择显著影响割的质量
- 找到好的乘数需要启发式（Gomory方法、MIR割等）

### Ralph Gomory与割平面的历史

Ralph Gomory在20世纪50年代后期开创了割平面方法——这是整数规划理论的突破性贡献。虽然割平面最初是主要的求解方法，现代求解器通常将其与分支定界结合在**分支割**框架中。

### 割平面方法要点

**算法:**
1. 求解当前问题的LP松弛
2. 如果最优解为整数：
   - **找到:** 最优IP解
3. 如果最优解为分数：
   - 生成**有效不等式**（割平面），满足：
     - 削除当前分数解
     - 不消除任何整数可行解
   - 将此约束加入问题
   - 返回步骤1（求解增广LP）

**重复:** 继续直到找到整数解

### 分支割算法

现代求解器使用称为**分支割**的混合方法：
- 开始使用分支定界
- 在分支过程中，动态添加割平面来改进界
- 这种组合比单独使用任一方法更高效

## 使用Gurobi实现

### 示例：衣服制造公司问题

**问题描述:**
一家衣服公司生产三类服装：衬衫、短裤和裤子。公司必须为每类服装租赁机器：
- 衬衫机器：200美元/周
- 短裤机器：150美元/周
- 裤子机器：100美元/周

**可用资源（每周）:**
- 劳动力：150小时
- 布料：160平方码

**产品信息:**

| 产品 | 劳动(小时) | 布料(平方码) | 可变成本 | 销售价格 |
|------|-----------|------------|--------|--------|
| 衬衫 | 3         | 4          | \$6    | \$12   |
| 短裤 | 2         | 3          | \$4    | \$8    |
| 裤子 | 6         | 4          | \$5    | \$15   |

### 决策变量

$$x_1 = \text{每周生产衬衫数量}$$
$$x_2 = \text{每周生产短裤数量}$$
$$x_3 = \text{每周生产裤子数量}$$

$$y_j = \begin{cases} 
1 & \text{若生产第 } j \text{ 类服装} \\
0 & \text{否则}
\end{cases} \text{ 对于 } j = 1, 2, 3$$

**解释:** 若 $x_j > 0$，则 $y_j = 1$；若 $x_j = 0$，则 $y_j = 0$。

### 目标函数

最大化周利润：
$$\text{周利润} = \text{（销售收入）} - \text{（可变成本）} - \text{（机器租赁成本）}$$

$$Z = (12 - 6)x_1 + (8 - 4)x_2 + (15 - 5)x_3 - 200y_1 - 150y_2 - 100y_3$$
$$Z = 6x_1 + 4x_2 + 10x_3 - 200y_1 - 150y_2 - 100y_3$$

### 完整的整数规划表述

$$\max \quad 6x_1 + 4x_2 + 10x_3 - 200y_1 - 150y_2 - 100y_3$$

**约束条件:**
$$3x_1 + 2x_2 + 6x_3 \leq 150 \quad \text{（劳动力约束）}$$
$$4x_1 + 3x_2 + 4x_3 \leq 160 \quad \text{（布料约束）}$$
$$x_j \leq M \cdot y_j \quad j = 1, 2, 3 \quad \text{（机器可用性）}$$
$$x_j \geq 0, \text{ 整数} \quad j = 1, 2, 3$$
$$y_j \in \{0, 1\} \quad j = 1, 2, 3$$

**注:** $M$ 是足够大的常数，确保当机器可用时big-M约束不起限制作用。

## 旅行商问题

### 问题定义

**旅行商问题(TSP):**
一名商人必须设计一条路线，使得：
- 访问每个城市恰好一次
- 回到起始位置
- 最小化总旅行距离（或时间/成本）

### TSP的应用

虽然名称涉及商人，但TSP有许多实际应用：
- **路由与物流:** 车辆路由、送货优化
- **制造:** 集成电路设计（布线问题）
- **天文:** 优化望远镜观测序列
- **艺术:** 计算艺术与设计问题

### 计算复杂性

#### 组合爆炸
可能的独立路线数随城市数量呈阶乘增长：

| 城市数 | 独立路线数 |
|--------|-----------|
| 3      | 1         |
| 4      | 3         |
| 5      | 12        |
| 6      | 60        |
| 8      | 20,160    |
| 10     | 1,814,400 |
| 12     | 239,500,800 |
| 20     | 1.2 × 10^18 |

这个快速增长解释了为什么精确算法对大规模实例变得不可行。

### 历史背景：P&G竞赛（1962）

宝洁公司提供10,000美元的竞赛奖金（相当于今天的80,000美元）来找到访问美国33个位置并从芝加哥出发返回芝加哥的最短路线。

这个经典问题突显了TSP的实际重要性。

### 计算特性

- **复杂性:** TSP是**NP困难**(Non-deterministic Polynomial-time hard)，意味着不存在已知的多项式时间精确算法
- **精确解:** 现代求解器可以最优求解包含超过30,000个"城市"的实例（包括微芯片布局问题）
- **近似解:** 非常大的实例（数百万个城市）可使用启发式在1%最优度内求解

### 启发式 vs 精确方法

**启发式方法:**
- 快速找到相当好的解
- 不保证解的质量
- 对非常大的问题实用

**精确整数规划方法:**
- 保证全局最优性
- 多种表述方式可用
- 考虑对称TSP（城市i到j的距离等于j到i的距离）

---

### 将TSP表述为整数规划（对称情况）

#### 二进制变量定义

$$x_{ij} = \begin{cases} 
1 & \text{若遍历城市 } i \text{ 到 } j \text{ 的弧，} i \neq j \\
0 & \text{否则}
\end{cases}$$

其中 $d_{ij}$ 是城市 $i$ 到城市 $j$ 的距离（$i \neq j$）。

#### 基础TSP表述

$$\min \quad \sum_{i \neq j} d_{ij} x_{ij}$$

**约束条件:**
$$\sum_{j \neq i} x_{ij} = 1 \quad \forall i \quad \text{（每个城市恰好一条出边）}$$
$$\sum_{i \neq j} x_{ij} = 1 \quad \forall j \quad \text{（每个城市恰好一条入边）}$$
$$x_{ij} \in \{0, 1\} \quad \forall i, j$$

**注:** 上述表述是不完整的。缺少一个重要的约束！

---

### 子路线问题

#### 问题：子路线约束

基础表述有一个临界缺陷：它可能允许**子路线**。

**定义:** 子路线是只连接城市子集的路线，满足度数约束但不访问所有城市。

**例子:** 假设城市为 {1, 2, 3, 4, 5}，子路线可能是：
- 子路线1: 1 → 2 → 3 → 1
- 子路线2: 4 → 5 → 4

两条子路线都满足度数约束但不构成有效的完整路线。

### 子路线消除约束

#### 关键观察

设 $S$ 是节点的真子集，$|S| \geq 3$（例如 $S = \{2, 3, 4, 7, 9\}$）：

1. 仅包含 $S$ 中节点的子路线恰好包含 $|S|$ 条弧
2. 通过完整网络的有效路线在 $S$ 中最多包含 $|S| - 1$ 条弧

#### 子路线消除约束

为了禁止 $S$ 上的任何子路线，添加：
$$\sum_{i \in S, j \in S, i \neq j} x_{ij} \leq |S| - 1$$

此约束对 $S$ 内所有可能的弧求和（不仅仅是活跃的弧），确保 $S$ 内无法形成子路线。

#### 完整TSP表述

$$\min \quad \sum_{i \neq j} d_{ij} x_{ij}$$

**约束条件:**
$$\sum_{j \neq i} x_{ij} = 1 \quad \forall i$$
$$\sum_{i \neq j} x_{ij} = 1 \quad \forall j$$
$$\sum_{i \in S, j \in S, i \neq j} x_{ij} \leq |S| - 1 \quad \forall S \subseteq N, |S| \geq 3$$
$$x_{ij} \in \{0, 1\} \quad \forall i, j$$

---

### 子路线约束的爆炸问题

#### 可扩展性问题

对于小规模网络（6-10个城市），显式添加所有子路线约束在计算上是可行的。然而，可能的子集数量呈指数增长：

$$\text{真子集数} = 2^n - 2$$

对于 $n = 20$ 个城市：超过100万个子集！  
对于 $n = 30$ 个城市：超过10亿个子集！

**结论:** 对于现实规模的问题，不能显式添加所有子路线约束。

#### 实际解决策略

**两种实用方法:**

1. **部分约束方法:**
   - 仅包含某些关键子路线约束
   - 求解得到的IP
   - 若解包含子路线，添加新约束并重新求解

2. **动态/延迟约束生成:**
   - 用仅度数约束（可能加上少数子路线约束）表述IP
   - 求解IP
   - 检查解是否包含子路线
   - 若有，添加被违反的子路线约束并重新求解
   - 重复直到找到有效路线

这种迭代方法避免了预先指定所有约束，同时保证了最优性。

## TSP的替代表述

虽然上述基于子路线的表述是一种方法，但存在其他表述方式：

### Miller-Tucker-Zemlin (MTZ) 表述

MTZ表述通过引入**连续变量** $u_i$ 表示城市 $i$ 被访问的"顺序"来避免指数增长的子路线约束：

$$u_i - u_j + (n-1)x_{ij} \leq n - 2 \quad \forall i, j$$

**优点:** 仅 $O(n^2)$ 额外约束，而非指数个  
**缺点:** 通常提供较弱的LP界

### 方法比较

不同表述在权衡中有所不同：
- **基于子路线:** 强界但约束指数增长
- **基于MTZ:** 多项式约束但界较弱
- **混合（分支割）:** 在分支定界过程中动态添加子路线约束

## 关键要点

### 分支定界
- 通过松弛整数约束并递归分割来系统求解IP的方法
- 实际表现好但无理论最坏情况保证
- 现代求解器中的基础技术

### 割平面
- 添加有效不等式来增强LP松弛
- Chvátal-Gomory割提供通用框架
- 现代求解器在分支定界过程中使用分支割来提高效率

### TSP与表述强度
- 同一问题的多种表述可有非常不同的LP松弛
- 更强的表述需要更少的分支
- 表述大小与界质量之间存在权衡

### 实际求解
- Gurobi等商业求解器实现了这些算法的精致版本
- 理解底层方法有助于：
  - 有效表述问题
  - 调整求解器参数
  - 识别本质困难的问题

## 附录：讨论笔记（问答备注）

### 1) 为什么在 $x_f$ 上分支为 $x_f \le 5$ 和 $x_f \ge 6$？
- 若LP解中某变量为分数，例如 $x_f=5.6$，则整数可行性要求 $x_f \le \lfloor 5.6 \rfloor = 5$ 或 $x_f \ge \lceil 5.6 \rceil = 6$。
- 这两个分支对该变量的所有整数可能性进行了完全分割（无重叠、无遗漏）。

### 2) 为什么即使LP最优是分数也能剪枝分支？
- 对于最大化问题，每个节点的LP最优值是该节点内任何整数解目标值的**上界**。
- 若节点上界 $\le$ 当前最好整数解的值，该节点不可能改进当前最优，因此可安全剪枝。

### 3) "当前最好整数解"从哪里来？
- **不是**只来自根节点LP。
- 可能来自：
  1. 某个节点的LP最优恰好是整数，
  2. 求解器启发式（早期找到可行MIP解），
  3. 任何已探索分支中找到的可行整数解。

### 4) 从IP开始，怎么又回到LP？
- 是的，这是故意的。
- 分支定界过程中会求解许多LP松弛：
  - 根节点LP松弛，
  - 分支后各节点的LP松弛，
  - 加上割和重新优化。
- 目标仍是IP最优性；LP是用来确定界和指导搜索的工具。

### 5) CG割：用向量 $u$ 乘是什么意思？
- 我们取约束的非负线性组合，乘数为 $u$。
- 得到：$u^T A x \le u^T b$。
- 对整数变量，可通过向下取整导出有效割（标准CG/Gomory推导）：
  $$\lfloor u^T A \rfloor x \le \lfloor u^T b \rfloor$$
- 该割应削除当前分数LP解，同时保留所有整数可行解。

### 6) 在实际中 $u$ 怎么选？
- 教学演示：通常手工选择以说明思想。
- 在求解器中：从LP基/tableau和分离例程自动生成（Gomory、MIR、流覆盖等）。
- 好的 $u$ 产生强割；差的 $u$ 改进不大。

### 7) 模型中的Big-M：为什么需要？
- 链接约束：$x_i \le M_i y_i$，其中 $y_i\in\{0,1\}$。
  - 若 $y_i=0$（不租机器）：强制 $x_i=0$。
  - 若 $y_i=1$（租机器）：允许生产到 $M_i$。
- 选择紧的 $M_i$（不要超大数值）以获得更好性能。
- 实用选择：
  $$M_i=\min\left(\left\lfloor\frac{L}{a_i}\right\rfloor,\left\lfloor\frac{C}{b_i}\right\rfloor\right)$$

### 8) 什么是根松弛（Root Relaxation）？
- 分支定界树**根节点**的LP松弛。
- 提供初始全局界，帮助判断MIP的难度。
- 现代求解器还在根节点生成割和启发式解，然后才进行深层分支。

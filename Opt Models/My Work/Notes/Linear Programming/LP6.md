## 一、单纯形法简介

### 历史背景

- **1940 年代**：George Dantzig 在军事后勤方面的早期工作，促成了单纯形法的发展
- **1947–1948**：Dantzig 在 von Neumann 讲座上得到启发，将可行点方法转化为系统的单纯形算法
- 在 IBM 701 计算机上的实现，展示了该算法的实用性与效率

### 核心思想

- 单纯形法是求解线性规划问题的经典算法
- 可手工求解小规模 LP
- **沿可行域的边系统移动**，从约束定义的可行区域出发寻找最优解
- 迭代直到无法继续改进，得到最优解

## 二、线性代数基础

### 2.1 矩阵与线性系统

- **矩阵**：任意 m×n 矩形数阵
- **列向量**：m×1 矩阵
- **行向量**：1×n 矩阵

### 2.2 矩阵运算

- 数乘、加法
- **转置**：A^T
- **矩阵乘法**：AB 有定义 ⟺ A 的列数 = B 的行数

### 2.3 线性相关与无关

- **线性相关**：存在非平凡线性组合使向量和为 0
- **线性无关**：只有平凡线性组合（所有系数为 0）能使向量和为 0

### 2.4 矩阵的秩 (Rank)

- 设 A 为 m×n 矩阵，行向量为 r₁,..., rₘ，R = {r₁,..., rₘ}
- **rank(A)** = R 中最大线性无关子集的向量个数

### 2.5 矩阵的逆与行列式

- **逆矩阵 A⁻¹**：满足 BA = AB = I（单位阵）
- 若 rank(A) < m，则 A⁻¹ 不存在
- **行列式**：方阵的标量值，在非线性规划中会用到

### 2.6 线性系统的矩阵表示

- 线性方程组可写为 **Ax = b**
- 若 A⁻¹ 存在，则解为 **x = A⁻¹b**

## 三、LP 的矩阵表示

一般 LP 有：
- n 个决策变量 x₁,..., xₙ
- m 个函数约束
- 约束可为 "≤"、"≥"、"="
- 变量可有界：xⱼ ≥ 0、xⱼ ≤ 0 或无界 (urs)

**矩阵形式**：max c^T x，s.t. Ax = b，x ≥ 0

---

## 四、LP 的标准形 (Standard Form)

LP 称为**标准形**，当且仅当：

1. 所有变量有**非负约束** (x ≥ 0)
2. 所有约束为**等式**
3. 所有约束**右端非负** (b ≥ 0)
4. 目标函数为**最大化**

**形式**：
```
max  c^T x
s.t. Ax = b
     x ≥ 0
```

---

## 五、LP 形式的转换

### 5.1 非正变量 (x ≤ 0)

令 x' = -x ≥ 0，用 x = -x' 代入原问题。

### 5.2 无界变量 (urs)

令 x = x⁺ - x⁻，其中 x⁺, x⁻ ≥ 0，代入后求解，再通过 x = x⁺ - x⁻ 还原。

### 5.3 不等式转等式

| 原约束 | 方法 | 新变量 |
|--------|------|--------|
| **≤** | 在左侧**加**松弛变量 | 松弛变量 s ≥ 0，表示**未使用资源** |
| **≥** | 在左侧**减**剩余变量 | 剩余变量 s ≥ 0，表示**超额满足** |

- `a₁x₁ + ... + aₙxₙ ≤ b` → `a₁x₁ + ... + aₙxₙ + s = b`，s ≥ 0
- `a₁x₁ + ... + aₙxₙ ≥ b` → `a₁x₁ + ... + aₙxₙ - s = b`，s ≥ 0

### 5.4 最小化转最大化

**min c^T x** 等价于 **max (-c^T x)**

## 六、单纯形法步骤总览

1. **建立 LP 模型**
2. **化为标准形**（引入松弛/剩余变量等）
3. **建立单纯形表 (Simplex Tableau)**
4. **选取可行域的一个顶点**（初始基可行解 BFS）
5. **寻找进基变量**：能改进目标函数的边
6. **停止条件**：找不到能改进目标的边 → 已达最优

---

## 七、单纯形法核心概念

### 7.1 基可行解 (BFS)

- **基变量 (BV)**：在单纯形表中对应单位矩阵列的变量
- **非基变量 (NBV)**：其余变量，通常取 0
- **基 (Basis)**：基变量对应的列构成的矩阵

### 7.2 进基变量 (Entering Variable)

- 从 NBV 中选取**能改进目标**的变量进基
- 通常选择**目标函数系数为正**的 NBV

### 7.3 出基变量 (Leaving Variable)

- 进基变量增大时，为保持可行性，需限制其增长
- 使用 **最小比值法则 (Minimum Ratio Test)**：
  - 对每个基变量，计算：RHS / 该变量在进基变量列中的系数
  - 取**最小非负比值**对应的基变量出基
- 若某列系数全 ≤ 0，则该变量无上界限制（可能无界）

### 7.4 主元 (Pivot) 操作

- 将单纯形表从一个形式变换到另一个形式的过程
- 进基变量所在列与出基变量所在行的交叉元素为主元

---

## 八、单纯形法迭代流程

1. 检查目标行：若所有 NBV 系数 ≤ 0 → **最优**
2. 否则选一个系数 > 0 的 NBV 作为进基变量
3. 用最小比值法则确定出基变量
4. 执行主元变换，更新单纯形表
5. 重复上述步骤

## 九、Python 矩阵运算 (numpy)

```python
import numpy as np

# 定义矩阵
matrix = np.array([[1, 2], [3, 4]])

# 求逆（需可逆，即行列式 ≠ 0）
inverse_matrix = np.linalg.inv(matrix)

# 求行列式
determinant = np.linalg.det(matrix)
```

注意：求逆前需确保矩阵可逆（行列式非零），且为方阵。

## 十、小结

| 主题 | 要点 |
|------|------|
| 标准形 | 最大化、等式约束、变量非负、右端非负 |
| 松弛变量 | ≤ 约束 → 加 s；表示未用资源 |
| 剩余变量 | ≥ 约束 → 减 s；表示超额满足 |
| BFS | 基变量对应单位矩阵，非基变量为 0 |
| 单纯形法 | 沿边移动，每次进基-出基-主元，直到最优 |

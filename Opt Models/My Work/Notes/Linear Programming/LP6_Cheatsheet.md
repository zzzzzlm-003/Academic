> ⚠️ **注意**：本次小测**不使用单纯形法**求解，重点在于图解法、对偶理论、互补松弛性等方法

---

## 📊 一、图解法 (Graphical Method)

### 适用条件
- ✅ **仅适用于 2 个决策变量**的 LP 问题
- ✅ 通过绘制可行域和目标函数等值线求解

### 解题步骤

#### Step 1: 绘制约束条件
1. 将每个约束化为等式，绘制直线
2. 确定可行域方向（≤ 在下方，≥ 在上方）
3. 找出所有约束的交集 → **可行域**

#### Step 2: 绘制目标函数等值线
- 目标函数：`z = c₁x₁ + c₂x₂`
- 固定 z 值，绘制直线：`x₂ = (z - c₁x₁)/c₂`
- 改变 z 值，得到**平行等值线族**

#### Step 3: 确定最优解
- **最大化问题**：沿目标函数梯度方向（c₁, c₂）移动等值线
- **最小化问题**：沿相反方向移动
- **最优解位置**：
  - 通常在最远的**顶点（corner point）**
  - 或沿**边界**（多重最优解）
  - 或**无界**（可行域无界且目标可无限改进）

### 关键概念

| 概念 | 说明 |
|------|------|
| **可行域** | 所有约束的交集，通常为凸多边形 |
| **顶点/角点** | 可行域的顶点，通常是最优解所在 |
| **等值线** | 目标函数值相同的点的集合 |
| **无界可行域** | 可行域延伸至无穷，但目标函数可能仍有界 |

### 特殊情况判断

- **唯一最优解**：等值线与可行域在唯一顶点相切
- **多重最优解**：等值线与可行域边界重合（整条边都是最优）
- **无界问题**：可行域无界，且目标函数可无限改进
- **无可行解**：约束矛盾，可行域为空

## 🔄 二、LP 形式转换（不求解）

### 标准形要求

LP 标准形必须满足：
1. ✅ **最大化**目标函数
2. ✅ **等式约束** (Ax = b)
3. ✅ **变量非负** (x ≥ 0)
4. ✅ **右端非负** (b ≥ 0)

### 转换规则速查表

#### 1. 变量转换

| 原变量类型 | 转换方法 | 示例 |
|-----------|---------|------|
| **x ≤ 0** | 令 x' = -x ≥ 0 | x = -x' |
| **x 无界 (urs)** | x = x⁺ - x⁻，x⁺, x⁻ ≥ 0 | 用两个非负变量表示 |

#### 2. 约束转换

| 原约束 | 转换方法 | 新变量含义 |
|--------|---------|-----------|
| **≤ 约束** | 加**松弛变量** s | s ≥ 0，表示**未使用资源** |
| **≥ 约束** | 减**剩余变量** s | s ≥ 0，表示**超额满足** |

**公式**：
- `∑aᵢxᵢ ≤ b` → `∑aᵢxᵢ + s = b`，s ≥ 0
- `∑aᵢxᵢ ≥ b` → `∑aᵢxᵢ - s = b`，s ≥ 0

#### 3. 目标函数转换

- **min c^T x** → **max (-c^T x)**

## ⚖️ 三、对偶理论 (Duality Theory)

### 基本概念

- **原始问题 (Primal)**：原 LP 问题
- **对偶问题 (Dual)**：构造的新 LP 问题
- **关系**：Primal 最大化 ⟺ Dual 最小化

### 标准形式转换

#### Primal (标准形)
```
max  c^T x
s.t. Ax ≤ b
     x ≥ 0
```

#### Dual
```
min  b^T y
s.t. A^T y ≥ c
     y ≥ 0
```

### 转换规则表（重要！）

| Primal (Max) | Dual (Min) |
|:------------|:----------|
| **i-th 约束 ≤** | **i-th 变量 yᵢ ≥ 0** |
| **i-th 约束 ≥** | **i-th 变量 yᵢ ≤ 0** |
| **i-th 约束 =** | **i-th 变量 yᵢ 无界 (urs)** |
| **j-th 变量 xⱼ ≥ 0** | **j-th 约束 ≥** |
| **j-th 变量 xⱼ ≤ 0** | **j-th 约束 ≤** |
| **j-th 变量 xⱼ 无界 (urs)** | **j-th 约束 =** |

### 记忆技巧
- **约束类型** → **对偶变量符号**
- **变量符号** → **对偶约束类型**

## 📐 四、对偶定理

### 1. 弱对偶性 (Weak Duality)

**定理**：对偶问题的任何可行解都是原始问题的上界

- 对任何可行解：**Primal 值 ≤ Dual 值**
- **推论**：
  - 若 Primal 无界 → Dual 必须不可行
  - 若 Dual 无界 → Primal 必须不可行
  - 两者可能都不可行

### 2. 强对偶性 (Strong Duality)

**定理**：若 Primal 有最优解，则 Dual 也有最优解，且**最优值相等**

- Primal 最优值 = Dual 最优值

### 3. 对偶关系表

| | Primal 不可行 | Primal 有界 | Primal 无界 |
|:---|:---|:---|:---|
| **Dual 不可行** | ✅ 可能 | ❌ 不可能 | ✅ 一定 |
| **Dual 有界** | ❌ 不可能 | ✅ 一定 | ❌ 不可能 |
| **Dual 无界** | ✅ 一定 | ❌ 不可能 | ❌ 不可能 |

## 🎯 五、互补松弛性 (Complementary Slackness)

### 核心思想

**在最优解中，松弛量与影子价格的乘积 = 0**

### 数学表述

#### 条件 1：原始约束的松弛
- 若原始约束**不紧**（有松弛）：`Aᵢx < bᵢ` → **yᵢ = 0**
- 若原始约束**紧**（无松弛）：`Aᵢx = bᵢ` → **yᵢ 可 > 0**

#### 条件 2：对偶约束的松弛
- 若原始变量**> 0**：`xⱼ > 0` → **对偶约束取等号** `(A^T)ⱼy = cⱼ`
- 若原始变量**= 0**：`xⱼ = 0` → 对偶约束可为严格不等式

### 验证最优性的步骤

给定一个原始解 x*，验证是否为最优：

1. **检查原始约束的紧性**
   - 计算每个约束的松弛量：`sᵢ = bᵢ - Aᵢx*`
   - 若 `sᵢ > 0` → `yᵢ = 0`
   - 若 `sᵢ = 0` → `yᵢ` 待定

2. **检查原始变量的正负**
   - 若 `xⱼ* > 0` → 对偶约束 `(A^T)ⱼy = cⱼ` 必须成立
   - 若 `xⱼ* = 0` → 对偶约束 `(A^T)ⱼy ≥ cⱼ` 即可

3. **求解对偶变量**
   - 利用上述条件建立方程组
   - 求解 y，检查是否满足所有对偶约束

4. **结论**
   - 若能找到满足所有条件的对偶解 → x* 是最优解
   - 否则 → x* 不是最优解

### 经济解释

- **资源有富余**（松弛 > 0）→ **影子价格 = 0**（资源不值钱）
- **资源价格 > 0** → **资源必须用尽**（松弛 = 0）

## 🔢 六、矩阵运算速查

### Python (numpy)

```python
import numpy as np

# 矩阵定义
A = np.array([[1, 2], [3, 4]])

# 转置
A_T = A.T  # 或 np.transpose(A)

# 矩阵乘法
C = A @ B  # 或 np.dot(A, B)

# 求逆（需可逆）
A_inv = np.linalg.inv(A)

# 求行列式
det = np.linalg.det(A)

# 解线性方程组 Ax = b
x = np.linalg.solve(A, b)
```

### 关键公式

- **矩阵乘法**：`(AB)^T = B^T A^T`
- **逆矩阵**：`(AB)^(-1) = B^(-1) A^(-1)`
- **转置的逆**：`(A^T)^(-1) = (A^(-1))^T`

## 📝 七、解题策略

### 图解法（2 变量）

1. ✅ 绘制所有约束直线
2. ✅ 确定可行域
3. ✅ 绘制目标函数等值线
4. ✅ 沿梯度方向移动，找最远顶点
5. ✅ 计算顶点坐标和目标值

### 对偶问题构造

1. ✅ 识别 Primal 的约束类型和变量符号
2. ✅ 应用转换规则表
3. ✅ 写出 Dual 问题
4. ✅ 检查 Dual 的可行性/有界性

### 互补松弛性验证

1. ✅ 给定原始解，计算约束松弛量
2. ✅ 应用互补松弛条件
3. ✅ 求解对偶变量
4. ✅ 验证对偶可行性
5. ✅ 得出结论

## ⚠️ 八、常见错误避免

### 图解法
- ❌ 忘记确定可行域方向
- ❌ 目标函数梯度方向搞反（max vs min）
- ❌ 混淆无界可行域和无界问题

### 对偶转换
- ❌ 约束类型和变量符号对应关系搞错
- ❌ 忘记转置矩阵 A^T
- ❌ 目标函数系数和右端项位置搞反

### 互补松弛性
- ❌ 混淆原始约束松弛和对偶约束松弛
- ❌ 忘记检查对偶解的可行性
- ❌ 条件应用错误（> 0 vs = 0）

## 🎓 记忆口诀

**图解法**：两变量，画约束，找可行域，移等值线，顶点最优

**对偶转换**：约束类型 → 变量符号，变量符号 → 约束类型

**互补松弛**：松弛 > 0 → 价格 = 0，价格 > 0 → 松弛 = 0

**弱对偶**：原始值 ≤ 对偶值（任何可行解）

**强对偶**：最优值 = 最优值（最优解时）
